# Game Modes and Rules

## Единая игровая база

Все режимы строятся на одном матчевом цикле:

1. старт матча
2. ввод попытки
3. валидация
4. scoring по точным совпадениям
5. обновление состояния матча
6. завершение или продолжение

## Режимы первого цикла

### PvE Race

- opponent provider: bot
- единый secret
- игра строится вокруг анализа попыток
- подсказки могут быть включены

### PvP Duel

- opponent provider: local human сейчас, remote player позже
- общий контракт матча сохраняется
- отличия режима лежат в mode definition и orchestration, а не в отдельной игровой логике

## Общие правила

- длина кода: `4..20`
- допускаются/запрещаются повторы по конфигу
- попытки типа `111111` могут запрещаться по конфигу
- выигрыш: score == codeLength
- проигрыш: исчерпан attemptLimit

## Принцип расширения

Новый режим должен добавляться через:

- новый `GameModeDefinition`
- нужный `OpponentProvider`
- настройки shell и UX

а не через копию отдельного движка.
