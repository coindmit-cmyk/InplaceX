## 2. Создание

Для создания игрового поля используются входящие параметры.
### 2.1 Параметры:

#### TypeGame(str)

Обязательный параметр.
Отвечает за отображение игрового режима RaceMatch или DuelMatch

#### UseHints(bool)

По умолчанию = True
Отвечает за использование подсказок в игре, разрешено или запрещено.
#### TimeAll(int)

По умолчанию = 0
Сколько времени отведено на эту игру в секундах. Если указано 0, то время бесконечное. Используется для режима RaceMatch

#### TimeMove(int)

По умолчанию = 0
Сколько времени отведено на ход в секундах. Если указано 0, то время бесконечное. Используется для режима DuelMatch
#### LimitMoves(int) 

По умолчанию = 0
Сколько отведено ходов на эту игру. Если указано 0, то количество ходов бесконечное. Используется для режима RaceMatch

#### LenSecret(int)

По умолчанию = 6
Длинна секретной комбинации.

#### SizeScreen(list)

Обязательный параметр. 
Берется из системы телефона и по нему настраивается размер элементов.
