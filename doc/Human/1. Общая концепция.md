Игра представляет собой логическую головоломку на угадывание скрытой числовой последовательности.

Игроку необходимо определить секретный код, состоящий из цифр, путем последовательных попыток. После каждой попытки игрок получает минимальную информацию — только количество цифр, которые полностью совпали с секретом по значению и позиции.

## 1.1. Базовая механика

- Секрет — это последовательность цифр фиксированной длины **N**
- Игрок делает попытку (guess) той же длины
- После каждой попытки возвращается число:

score = количество позиций i, где guess[i] == secret[i]

## 1.2. Особенности механики

- Учитываются **только точные совпадения**
- Совпадения цифр вне своей позиции **не учитываются**
- Режим без повторов/с повторами. Детальнее в разделе 1.8 [[#^d4197f]]

## 1.3. Ключевая идея

Игровой процесс основан на:

- последовательном **сужении множества возможных решений**
- анализе предыдущих попыток и полученных ответов

Игрок должен:

- строить гипотезы
- проверять их
- исключать невозможные варианты

## 1.4. Типы взаимодействия

Игра поддерживает два принципиально разных подхода:

1. **Асимметричный (дуэль)**
    - игроки загадывают числа друг другу
    - ходы выполняются по очереди
2. **Симметричный (гонка)**
    - один общий секрет для всех игроков
    - участники угадывают параллельно

## 1.5. Ограничения на попытки

Для повышения качества геймплея вводятся ограничения:

- Запрещены “дегенеративные” попытки:
    - примеры: `111111`, `222222`, и аналогичные шаблоны
- Ограничения направлены на:
    - предотвращение тривиального перебора
    - повышение значимости стратегии

## 1.6. Цель игры

Цель игрока:

- определить секретную последовательность
- за минимальное количество попыток или минимальное время

В PvP режимах:

- превзойти соперника по скорости или эффективности

## 1.7. Позиционирование

Игра относится к категории:

- логических головоломок
- информационных игр (inference games)

И сочетает элементы:

- стратегического анализа
- вероятностного мышления
- оптимизации поиска

## 1.8. Политика повторов цифр ^d4197f

В игре используется два варианта формирования секретного кода:

### Основной режим (по умолчанию)

- **Повторы цифр разрешены**
- Используется:
    - PvP (дуэль)
    - PvP (гонка)
    - основной геймплей

Причины:

- максимальная вариативность
- выше сложность
- глубже стратегия

---

### Упрощённый режим

- **Повторы запрещены**
- Используется:
    - игра с ботом (низкая сложность)
    - обучение / onboarding

Причины:

- быстрее сужается пространство решений
- проще для новых игроков
- меньше “хаоса” в логике
