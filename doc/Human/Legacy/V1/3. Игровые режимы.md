Игра включает несколько режимов, отличающихся структурой взаимодействия, условиями победы и назначением.

## 3.1. Общая классификация игровых экранов

Режимы делятся на две группы:

- **DuelMatch** 
- **RaceMatch**

Это главные игровые окна из них будут собираться уже режимы.

### 3.1.1. **DuelMatch**

Окно режима где два участника, каждый загадывает свое число и по очереди отгадывают число соперника. Время на ход может быть ограничено.

#### Механика

- игрок/игроки вводит свой секрет(бот генерирует свой).
- ходы выполняются по очереди.
- ход может быть ограничен по времени.

#### Условия победы

- кто первым угадывает секрет соперника — побеждает

### 3.1.2. **RaceMatch**

Окно режима где неизвестно сколько участников. Главное это как можно быстрее и за меньшее число попыток угадать число.

#### Механика 

- секрет генерируется автоматически(Для pve игры на устройстве, для pvp на сервере).
- одинаков для игрока, игроков, бота.
- попытки выполняются параллельно.
- ответы выдаются сразу.
- ограничения на попытки(Может отсутствовать ограничение).
- ограничение на общее время(Может отсутствовать ограничение).

#### Условия победы

1. меньшее количество попыток
2. при равенстве — меньшее время
