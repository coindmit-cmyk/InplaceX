# InplaceX Agent Guide

This file is the entry point for AI agents working on InplaceX.

Before changing files:

1. Read `.agent/START_HERE.md`.
2. Read `docs/automation/PROJECT_HOST_ASSIGNMENTS.md`.
3. Refresh the configured Git base branch and inspect the worktree.
4. Preserve unrelated user changes.

Communicate with the project owner in Russian unless they ask otherwise.
Keep AI-facing operational contracts in English. Never add credentials,
private keys, tokens, passwords or real VPS endpoints to tracked files.
