exact branch и получения terminal exact-SHA CI evidence.

предоставить инфраструктурную KVM authority.

1. KVM-capable GitHub/self-hosted runner для instrumentation job.
2. Поддерживаемый Android emulator action и runner configuration, которые
   реально обеспечивают доступ к KVM и boot API 34 emulator.
