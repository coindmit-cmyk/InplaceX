## Где лежит история

Локальный архив владельца:

```text
E:\MyProgectHistory\InplaceX\cleanup-20261019
```

`unique-history.bundle` хранит уникальную историю относительно исходного
`develop` `2263510f158c36fc9fe982628f4c98bfcd5f9f6f`. Общая основа остаётся в Git.
`worktrees/*/manifest.json`, бинарные patches и хранилище `objects/` сохраняют
только изменённые и локальные файлы с SHA-256. Полные копии проекта для каждой
старой версии не создавались. Исторические документы доступны в `documents/`.

Для просмотра сохранённых изменений конкретной рабочей копии:

```powershell
python E:/MyProgectHistory/InplaceX/cleanup-20261019/restore_delta.py <worktree_id> D:/tmp/InplaceX-delta-review
```

Команда требует новый или пустой каталог и восстанавливает только сохранённые
изменения. Удалённые пути перечисляет отдельно; основной проект не изменяет.
Сопоставление исходных каталогов и `worktree_id` находится в
`evidence/archived-worktrees.json`.

и публикация веток не выполнялись.

Попытка объединения APK updater сохранена как
`evidence/sdk-update-pending.patch`; некомпилируемый вариант отменён в изолированной

разрешённого модельного маршрута. Затем нужно квалифицировать оставшиеся ветки,
включая рекламу, UI, SDK и прототип platform identity, и повторить их проверки.

Точный текущий список и незавершённые пункты приведены в архивных отчёте и
снимке состояния; успешное архивирование не означает интеграцию разработки.
