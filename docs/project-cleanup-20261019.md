# Очистка InplaceX — 19 октября 2026

Локально оставлены две ветки: `develop` и `release`. Все 156 исходных вершин
локальных веток входят в историю `develop`; это проверено через Git ancestry.
Система, очередь задач, паузы и локальные инструкции сохранены. История и
уникальные локальные изменения находятся на E: в виде дельт.

После явного решения владельца интеграция продолжена через чат. Прежние
квитанции Luna, включая отказ по загрузке и неизвестный расход, сохранены;
новые платные CLI-вызовы не выполнялись.

## Что уже сделано

- Проверенные исправления ревизии A02–A11 и сохранённая серия изменений ядра,
  рекламы, авторизации и логирования объединены с актуальным `develop`.
- При конфликтах сохранены актуальные восстановление игры, локализация,
  доступность интерфейса и онлайн-оболочка. Старая обработка downgrade с удалением
  таблиц не перенесена.
- Эквивалентные патчи подтверждены через Git; объединение их истории не меняет
  дерево файлов. Старые рабочие каталоги убраны после сохранения уникальных данных.
- Локальные инструкции и текущая очередь задач сохранены побайтно. Паузы,
  исходные ID заданий и аппаратные ограничения не менялись.
- Старые материалы из `old/`, `InplaceX-docs/Legacy/` и backend Temporary вынесены
  в архив. Сведения второго мозга проверены и сохранены с ссылками на источники.
- APK updater интегрирован с текущим SDK: сохранены существующие API каталога,
  платежей, социальных связей и дистрибутивов. Только подписанный RF-кандидат
  получает установщик; он использует текущий distribution-aware каталог.
  Проверки пакета, версии, SHA-256, подписи, обязательной политики и жизненного
  цикла сохранены. Обычные release/debug и Google Play сохраняют свой поток.
- Для остальных 24 веток зафиксирована проверка актуальной реализации или её
  замены более поздним контрактом. Старые фиксированные размеры не заменяют
  доступную типографику; карточка бота не раскрывает комбинации; миграции V3/V9
  не переписываются. Старые AdMob/Huawei-адаптеры остаются историческим прототипом
  без активации новых SDK и рекламных кабинетов. Решения по каждой ветке:
  `branch-decisions-chat.json` в архиве.
- Прототип общих аккаунтов сохранён как проверенная дельта из 13 файлов.
  Его архитектурное решение реализовано позднее через Mirkori Platform;
  перенос старой V9 в игровую БД создал бы конфликт номера и владельца данных.
- Из 111 исходных существовавших рабочих каталогов остались основной проект
  и сохранённый релиз; 30 отсутствовавших регистраций убраны. Ветка `release`
  указывает на сохранённый локальный релиз `c05d26b3`; текущая версия production
  в ходе очистки не устанавливалась и не менялась.

## Где лежит история

Локальный архив владельца:

```text
E:\MyProgectHistory\InplaceX\cleanup-20261019
```

`unique-history.bundle` хранит уникальную историю относительно исходного
`develop` `2263510f158c36fc9fe982628f4c98bfcd5f9f6f`. Общая основа остаётся в Git.
`worktrees/*/manifest.json`, бинарные patches и хранилище `objects/` сохраняют
только изменённые и локальные файлы с SHA-256. Полные копии проекта для каждой
старой версии не создавались. Исторические документы доступны в `documents/`.

Для просмотра сохранённых изменений конкретной рабочей копии:

```powershell
python E:/MyProgectHistory/InplaceX/cleanup-20261019/restore_delta.py <worktree_id> D:/tmp/InplaceX-delta-review
```

Команда требует новый или пустой каталог и восстанавливает только сохранённые
изменения. Удалённые пути перечисляет отдельно; основной проект не изменяет.
Сопоставление исходных каталогов и `worktree_id` находится в
`evidence/archived-worktrees.json`.

## Проверка и продолжение

Журнал `evidence/final-develop-check.log` содержит проверку неизменённых backend,
ядра, логирования, авторизации и рекламы. Новые журналы
`evidence/updater-chat-check-3.log` и `evidence/updater-candidate-check.log`
подтверждают SDK-тесты, Android Global Debug, RF Release, подписанный RF-кандидат
и компиляцию Android UI-тестов. Проверены реальные merged manifests трёх
вариантов, 25 release-distribution тестов, 17 отрицательных CI-мутаций и
18 запусков проверки APK identity с фикстурами.

Физические устройства в ходе очистки не использовались. Production deployment
и публикация веток не выполнялись. Исходный некомпилируемый вариант SDK сохранён
как диагностическая дельта; исправленный merge принят после проверок.

Ранее автоматическая проверка разрешений запрещала нативное удаление
осиротевшего `InplaceX-auth-profile-choice`. Финальная проверка файловой системы
подтвердила, что этот каталог уже отсутствует; автор удаления не предполагается.
Его исходная история и локальные файлы сохранены. Пустые контейнеры `worktrees`
остаются служебными каталогами и не содержат копий проекта.
