# Artifact Discovery Scope

Artifact Discovery is project-wide and project-neutral.

It is intended to find:

- missing map coverage;
- missing index links;
- missing script catalog entries;
- missing schema/template pairs;
- missing integration surfaces;
- missing UX contract/waiver signals;
- legacy state references;
- cleanup candidates;
- lost task candidates;
- lost documentation;
- policy drift;
- sensitive-risk patterns.

It does not replace Product Design, UX Design, ProjectMapPlanner, Dispatcher, Integrator, Doctor or Finalizer.
