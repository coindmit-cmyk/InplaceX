# Artifact Discovery Primer

Artifact Discovery is the common radar for repository artifacts.

Use it when you need to know whether the repository contains:

- files not represented in the project map;
- docs not linked from indexes;
- scripts not linked from catalogs;
- schemas without templates;
- legacy references that contradict current rules;
- cleanup candidates;
- human-facing artifacts without UX disposition;
- current/new artifacts that need integration before finalization.
