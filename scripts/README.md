# Scripts

Этот каталог зарезервирован для внутренних скриптов разработки, диагностики и автоматизации.

Правила:

- скрипты должны быть dev-only/internal;
- скрипты не должны требоваться обычным пользователям приложения;
- скрипты не должны хранить секреты или локальные provider ids;
- для повторяющихся Gradle-проверок сначала используйте существующие задачи root build.

Текущие основные команды уже доступны через Gradle:

```powershell
.\gradlew.bat verifyProject
.\gradlew.bat assembleDebug
.\gradlew.bat cleanLocalDiagnostics
```
