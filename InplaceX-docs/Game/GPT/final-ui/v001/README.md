# InplaceX Final UI Package v1

Пакет фиксирует финальный UX/UI-pass для Android-клиента InplaceX и предназначен для реализации через Codex без повторного придумывания интерфейса.

## База

- Репозиторий: `coindmit-cmyk/InplaceX`
- Ветка: `develop`
- Проверенный commit: `5f37f4e138f96cdf70c489237b28137a351b3892`
- Пакет: `INPLACEX-FINAL-UI-20260812-v001`
- Направление: **яркая тёплая комната + аккуратный premium-casual UI**

Если `develop` уже ушёл вперёд, Codex обязан сначала обновить checkout, сравнить затронутые UI-файлы с этой базой и адаптировать пакет. Применять код вслепую нельзя.

## Источники истины по приоритету

1. `00_OWNER_DECISIONS.md` — решения владельца, не подлежащие переосмыслению.
2. `01_UX_CONTRACT.md` — функциональный UX-контракт.
3. `02_VISUAL_SYSTEM.md` и Kotlin-токены — точные визуальные настройки.
4. Текущий код и тесты — поведение, состояние, навигация и интеграции.
5. Технические схемы `references/gameplay_*.png` — геометрия и плотность.
6. `references/approved_mood_only.png` — только настроение; не источник размеров.

Сгенерированная ранее коричнево-бежевая «спецификация» отвергнута и в пакет не включена.

## Главное решение

Это **не редизайн продукта с нуля**. Сохраняются текущий фон `toy_room_bg_v6.png`, структура экранов, верхний HUD, нижняя навигация, игровые функции и компоновка поля. Улучшаются поверхности, иерархия, плотность, типографика, состояния и согласованность компонентов.

## Состав

- `00_OWNER_DECISIONS.md` — зафиксированные решения.
- `01_UX_CONTRACT.md` — UX-контракт и состояния.
- `02_VISUAL_SYSTEM.md` — цвета, размеры, тени, сетка, типографика, motion.
- `03_SCREEN_SPECS.md` — требования по каждому экрану.
- `04_COMPONENT_CONTRACTS.md` — анатомия компонентов.
- `05_IMPLEMENTATION_MAP.md` — точное соответствие текущим Kotlin-файлам.
- `06_ACCEPTANCE_AND_QA.md` — критерии приёмки и проверки.
- `07_TASK_CANDIDATES.json` — четыре безопасных вертикальных среза для Dispatcher/Codex.
- `08_VISUAL_CAPTURE_MANIFEST.json` — обязательная матрица скриншотов.
- `09_CODEX_MASTER_PROMPT.md` — готовый основной файл задания для Codex.
- `CODEX_FINAL_UI_PACKET.md` — консолидированная версия ключевых требований одним файлом.
- `code/FinalUiTokens.kt` — готовые точные токены.
- `code/FinalUiPrimitives.kt` — готовые базовые Compose-компоненты.
- `code/IntegrationExamples.md` — примеры интеграции без изменения механики.
- `references/` — текущие экраны, mood reference и технические схемы.

## Рекомендуемое использование

1. Поместить каталог в репозиторий, например: `docs/00_dispatch/design-sessions/inplacex-final-ui/v001/`.
2. Передать Codex файл `09_CODEX_MASTER_PROMPT.md`.
3. Реализовывать задачи из `07_TASK_CANDIDATES.json` последовательно, отдельными коммитами или PR.
4. После первого gameplay-среза остановиться на визуальную приёмку владельцем, затем продолжить остальные экраны.

## Что пакет намеренно не делает

- не меняет game rules, scoring, inference, state holder, ViewModel или backend;
- не вводит новый шрифт и не добавляет лицензионные риски;
- не заменяет Compose-поверхности картинками;
- не меняет рекламу, покупки, авторизацию или сетевые контракты;
- не ограничивает существующие online-коды 4–10 цифр.
