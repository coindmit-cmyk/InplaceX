# Vision

## Продуктовая цель

InplaceX — логическая игра на угадывание цифровой последовательности, которая должна развиваться в две стороны одновременно:

- как самостоятельная игра с несколькими режимами
- как reusable game platform для похожих игр и вариаций

## Главный принцип

Приоритет у игры, но архитектура не должна запирать нас в одном Android-клиенте и одном режиме.

## Базовая ставка

- первый реальный клиент: Android
- архитектура: Android-first, web-ready
- бот и онлайн считаются разными opponent provider поверх одного match contract
- документация является главным проектным центром

## Что считаем успехом

- можно понять продукт, не читая код
- можно добавлять режимы без переписывания ядра
- общий shell и сервисы переиспользуются между будущими играми
- тексты, названия, branding и часть конфигов не размазаны по UI-коду
