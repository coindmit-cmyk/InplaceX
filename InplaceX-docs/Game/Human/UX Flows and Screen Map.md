# UX Flows and Screen Map

## Главный поток

`home -> mode select -> match -> result/restart`

## Shell-экраны первого уровня

- Главная
- Играть / Social
- Компания
- Магазин
- Профиль

## Игровой поток

- пользователь выбирает режим
- режим подставляет mode definition
- UI строит экран под общие параметры матча
- match engine управляет состоянием
- `WON` или `LOST` открывает обязательный результат матча
- результат показывает исход, попытки, время и полученную награду
- игрок явно выбирает повтор матча или возврат на главный экран

## UX-приоритеты

- быстрый вход в игру
- все основные режимы первого этапа доступны из главного меню
- читаемое состояние матча
- единый нижний shell
- адаптация под размеры экрана без ручной перепаковки каждого экрана

## Этапность online-функций

- `Company` занимает место отдельной shell-секции до запуска полноценных online-турниров
- турниры возвращаются позже как online-направление
- на переходном этапе online-матчи могут использовать bot fallback, если реальный соперник недоступен
