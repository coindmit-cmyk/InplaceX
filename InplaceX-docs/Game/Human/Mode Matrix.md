# Mode Matrix

## Base Match Types

В основе InplaceX лежат не множество разных игровых механик, а два базовых типа матча:

- `Duel`
- `Race`

Именно они считаются главными игровыми основаниями проекта.

`Duel` и `Race` задают:

- структуру хода
- способ появления secret
- общий ритм матча
- базовую форму игрового поля

Разница между ними в первую очередь определяется:

- моментом хода
- способом загадывания числа
- порядком взаимодействия участников с матчем

## Derived Game Modes

Все игровые режимы InplaceX строятся поверх двух базовых типов.

К режимам проекта относятся:

- `PvE Race`
- `PvP Duel`
- `PvE Duel with bot`
- `PvP Race`
- `Company`
- `Duel Tournament`
- `Race Tournament`

При этом:

- `Company` использует основу `PvE Race` с постепенным усложнением
- турниры не вводят новую базовую механику, а используют уже существующие типы `Duel` и `Race`
- новые режимы должны по возможности собираться из уже существующих оснований, а не создавать третье отдельное игровое поле

## UI Reuse Principle

Для InplaceX не планируется отдельный уникальный экран под каждый режим.

Базово проект должен опираться на два игровых поля:

- поле `Duel`
- поле `Race`

Дальше режимы должны адаптироваться поверх них через:

- настройки режима
- небольшие изменения UI
- правила запуска матча
- opponent orchestration
- backend-логику

Основные различия между режимами в будущем ожидаются не столько в экране, сколько:

- в orchestration
- в серверной логике
- в правилах подключения участников
- в источнике secret
- в матчевых ограничениях конкретного режима
