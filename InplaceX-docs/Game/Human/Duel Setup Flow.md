# Duel Setup Flow

## Общий принцип

`Duel` отличается от `Race` тем, что перед стартом матча участники сами задают свои secret.

Этот этап обязателен для дуэли и входит в её основной flow.

## Базовый сценарий

1. пользователь выбирает дуэльный режим
2. матч переходит в фазу подготовки
3. первый участник задаёт свой secret
4. второй участник задаёт свой secret
5. после ввода обоих secret матч переходит в активную фазу дуэли

## Текущее решение в UI

На текущем этапе setup-фаза дуэли реализуется через всплывающее окно.

Это значит:

- setup не является отдельным самостоятельным экраном
- setup является частью дуэльного flow
- основной экран дуэли продолжает использоваться как базовое игровое поле

## Правила setup-фазы

- ввод secret идёт по очереди
- secret одного участника не должен раскрываться другому
- обычный ввод попытки не должен смешиваться с вводом secret
- матч не должен стартовать, пока оба secret не заданы

## Bot в дуэли

Если одним из участников является bot, он работает в рамках того же общего дуэльного контракта.

Разница только в том, что secret bot создаётся своей логикой, а не ручным вводом.

## Local и future online duel

Local duel и future online duel должны сохранять один и тот же смысл setup-фазы.

Различия между ними должны лежать в orchestration и backend-логике, а не в изменении самой сути дуэльного setup.
