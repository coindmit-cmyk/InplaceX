# Друзья и онлайн: первый рабочий срез

## Цель

Два телефона должны входить в одну серверную дуэль без Google-авторизации.
Каждая установка получает собственную гостевую учётную запись на VPS.

## Разделы

- `Друзья` показывает сохранённый список друзей, входящие приглашения и
  тестового серверного бота.
- Поиск игрока работает по имени, публичному ID или полному ID профиля Mirkori.
  Добавление создаёт серверную заявку: второй игрок получает уведомление и
  принимает её в разделе `Друзья`.
- `Приглашения` содержит только создание приватной игры и вход по коду.
- `Онлайн-матчи` содержит только быстрый поиск случайного соперника с bot fallback.

Эти разделы не должны открывать один и тот же смешанный экран настроек.

## Приватная игра

1. Первый игрок открывает `Друзья`, нажимает `Играть` у нужного человека,
   выбирает формат и нажимает `Отправить приглашение`.
2. Сервер создаёт адресное приглашение на 10 минут и возвращает резервный код.
3. У второго игрока появляется Android-уведомление, счётчик на разделе Social
   и карточка приглашения в `Друзья`. Он может нажать `Принять`.
4. Если уведомление не видно, тот же человек вводит восьмизначный код через
   `Приглашения` → `Войти по коду`.
5. После подключения оба задают собственные секреты.
6. Сервер определяет очерёдность, проверяет ходы и возвращает общий результат.

Экран автоматически опрашивает сервер во время ожидания второго телефона,
секрета и хода. Ручное обновление не требуется.

Отправленное приглашение сохраняется отдельно для текущего игрового профиля.
После пересоздания экрана или приложения возврат в Social восстанавливает
ожидание по тому же коду; если друг уже принял приглашение, открывается матч.
Временная ошибка связи сохраняет код и позволяет повторить восстановление.
Истечение срока или явная отмена ожидания очищают локальный маркер. Отмена
ожидания пока не отзывает код на сервере — он действует до своего срока.
Сохранённое ожидание восстанавливается только через экран приглашений: новое
нажатие «Найти матч» или вызов другого друга не подменяется старым кодом. Если
игровой профиль загрузился уже после открытия Social, его код применяется один
раз. Повтор после ошибки заново выполняет именно неудавшееся действие — принятие
входящего приглашения, восстановление активного матча или ожидания владельца.
Нажатие Android-уведомления открывает Social, но не принимает заявку или матч
без явного действия игрока.

Онлайн-поле использует общий обработчик свободных позиций с локальной игрой.
Например, при автоматически подтверждённых `***55**` пять нажатий `1` дают
`1115511`: подтверждённые позиции не расходуют ввод и пропускаются при удалении.
При выключенной автотаблице автоматические выводы не подставляются скрыто
в отправляемую комбинацию.

## Быстрый матч

Быстрый поиск остаётся отдельным действием. Сервер сначала ищет другого
гостевого игрока, а после ограниченного ожидания подключает серверного бота.
Приватное приглашение никогда не заменяет друга ботом.

На главном экране и `Race`, и `Duel` сначала предлагают выбрать соперника:
бота или онлайн-матч. Онлайн-переход сохраняет формат выбранного режима.

## Ограничения staging

- Принятые друзья хранятся в Mirkori Games Platform и синхронизируются в
  локальный список приложения. `Mirkori Bot` остаётся тестовым другом; при
  отсутствии online-конфигурации запуск матча блокируется явным
  offline-состоянием;
- приложение опрашивает backend при запущенном процессе и показывает обычное
  Android-уведомление, in-app badge и карточку; provider push при полностью
  выгруженном приложении пока не входит в этот компактный срез;
- адресные приглашения и активные матчи переживают перезапуск игрового backend;
- Google не требуется, но без него гостевой профиль нельзя восстановить на
  другом устройстве после потери локальной сессии.
