# Roadmap

## Stage 1

- закрепить каноническую структуру документации
- свести core к одному матчевому контракту
- вынести базовые platform contracts
- перевести часть shell и mode-настроек в центральные конфиги

## Stage 2

- расширить mode definitions
- унифицировать legacy screen flows
- подготовить bot provider как отдельный слой orchestration
- добрать unit tests вокруг core contracts

## Stage 3

- развести модули физически
- подготовить web-ready boundaries
- расширить online contracts до реальных адаптеров

## Stage 4

- reusable game platform для новых игр на том же каркасе
