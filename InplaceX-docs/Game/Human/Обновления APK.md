# Обновления APK

## Как игра узнаёт об обновлении

При запуске и после возвращения в игру InplaceX спрашивает публичный каталог
Mirkori Games Platform о последней стабильной Android-версии. Проверка
использует только номер установленной версии и не зависит от того, играет
пользователь как гость или вошёл в аккаунт.

Повторные запросы ограничены: при актуальной версии игра ждёт шесть часов, а
после временной ошибки — пятнадцать минут. Эти паузы сохраняются после
перезапуска приложения.

## Необязательное обновление

Если старая версия ещё поддерживается, окно предлагает скачать APK или выбрать
«Позже». Игра остаётся полностью доступной. Выбор «Позже» сохраняется на 24
часа только для этой конкретной версии; новый релиз будет показан отдельно.

## Обязательное обновление

Если установленная версия ниже минимально поддерживаемой, окно нельзя закрыть.
В нём остаётся явная кнопка «Скачать и проверить». Отложенное ранее необязательное
обновление не может скрыть обязательное.

## Безопасность скачивания

Игра принимает ссылку только с настроенного домена Mirkori Games и только по
HTTPS. Ссылка должна точно указывать на неизменяемый файл релиза из
проверенного каталога. Тестовый SDK умеет обращаться по обычному HTTP только к
локальному адресу разработчика, но updater в debug-сборке полностью отключён.

Публикуемая подписанная сборка скачивает APK только во внутренний временный кэш
InplaceX. Игра не следует перенаправлениям, сверяет заявленный размер и SHA-256,
а затем проверяет пакет, версию, минимальную версию Android, отсутствие debug-
флага и всю цепочку ключей подписи. Неполный или неподходящий файл удаляется.

После успешной проверки Android попросит разрешить InplaceX установку из этого
источника и откроет стандартный системный установщик. Сам системный установщик
выполняет окончательную криптографическую проверку подписи. Debug, обычный
release и внутренняя сборка не имеют такого разрешения и не запускают updater.

Если обязательное обновление уже найдено, оно сохраняется до сетевого запроса
и не исчезает после перезапуска или временного офлайна. Каталог при следующей
успешной проверке может заменить или отозвать релиз. Несовместимая версия
Android показывается отдельным понятным состоянием.

До публикации владелец должен добавить подписанный APK и его точные размер,
SHA-256, имя пакета, цепочку сертификатов, минимальную версию Android и
`minimumSupportedVersionCode` в production-каталог Mirkori Games.
