# Обновления APK

## Как игра узнаёт об обновлении

При запуске и после возвращения в игру InplaceX спрашивает публичный каталог
Mirkori Games Platform о последней стабильной Android-версии. Проверка
использует только номер установленной версии и не зависит от того, играет
пользователь как гость или вошёл в аккаунт.

Повторные запросы ограничены: при актуальной версии игра ждёт шесть часов, а
после временной ошибки — пятнадцать минут. Эти паузы сохраняются после
перезапуска приложения.

## Необязательное обновление

Если старая версия ещё поддерживается, окно предлагает скачать APK или выбрать
«Позже». Игра остаётся полностью доступной. Выбор «Позже» сохраняется на 24
часа только для этой конкретной версии; новый релиз будет показан отдельно.

## Обязательное обновление

Если установленная версия ниже минимально поддерживаемой, окно нельзя закрыть.
В нём остаётся явная кнопка «Скачать APK». Отложенное ранее необязательное
обновление не может скрыть обязательное.

## Безопасность скачивания

Игра принимает ссылку только с настроенного домена Mirkori Games и только по
HTTPS. Ссылка должна точно указывать на неизменяемый файл релиза из
проверенного каталога. Исключение для обычного HTTP существует только в debug
сборке и только для локального адреса разработчика.

Первая версия механизма открывает ссылку во внешнем браузере. InplaceX не
скачивает APK в своё хранилище, не просит разрешение на установку приложений и
не обходит системную проверку подписи Android. Для обновления поверх уже
установленной игры APK должен быть подписан тем же release-ключом.

До публикации владелец должен добавить подписанный APK и его точные размер,
SHA-256 и минимально поддерживаемую версию в production-каталог Mirkori Games.
