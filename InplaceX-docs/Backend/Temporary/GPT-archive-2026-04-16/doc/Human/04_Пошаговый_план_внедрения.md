# Пошаговый план внедрения

## Релиз 1
Цель: backend как основа.

Сделать:
- отдельный backend repo
- auth guest
- config endpoint
- progress endpoint
- access/refresh tokens
- Android network/auth/config layers

Результат:
- приложение уже умеет жить не только локально

## Релиз 2
Цель: rewarded ads безопасно.

Сделать:
- ads abstraction
- provider router
- reward sessions на backend
- AdMob global
- Yandex fallback spec
- выдача награды только через backend

Результат:
- монетизация не прибита к UI

## Релиз 3
Цель: аккаунт и перенос прогресса.

Сделать:
- Google link
- session restore
- merge local/cloud
- device migration
- basic anti-abuse
- Play Integrity на sensitive endpoints

Результат:
- прогресс не теряется при смене устройства

## Релиз 4
Цель: multiplayer.

Сделать:
- rooms
- invites
- websocket
- duel
- race
- room state
- match history

Результат:
- честное PvP через сервер

## Релиз 5
Цель: social + tournaments.

Сделать:
- party rooms
- tournament brackets
- ranking
- moderation/admin tools
- notifications

## Главный принцип

Не начинать с турниров, пока нет:
- auth
- progress
- room lifecycle
- authoritative match processing
