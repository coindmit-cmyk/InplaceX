# Что лежит в архиве

Этот архив — рабочая спецификация под следующую фазу проекта.

## Блоки

### Backend
Где живут:
- прогресс
- аккаунты
- cloud save
- рекламные награды
- комнаты
- матчи
- турниры

### Ads
Как встроить rewarded ads так, чтобы:
- не размазывать SDK по UI
- можно было менять провайдера по региону
- награда не выдавалась напрямую из клиентского callback

### Connection
Как сделать:
- guest-вход
- линковку Google
- cloud save
- REST + WebSocket
- устойчивость к плохой сети
- антиабуз на чувствительных запросах

## Куда класть

- `doc/Human/*` — можно оставить как есть
- `doc/GPT/Doc For Codex/*` — новая папка для машинной документации
- backend-код лучше держать в **отдельном репозитории**, не внутри Android-проекта
