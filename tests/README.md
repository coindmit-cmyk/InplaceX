# Tests

Этот каталог зарезервирован для будущих корневых integration/e2e тестов, если они появятся.

Сейчас тесты находятся рядом с модулями:

- `InplaceX-bot-core/src/test`
- `InplaceX-logging/src/test`
- `InplaceX-backend/src/test`
- `InplaceX-android/app/src/test`
- `InplaceX-android/app/src/androidTest`

Основная проверка проекта:

```powershell
.\gradlew.bat verifyProject
```
