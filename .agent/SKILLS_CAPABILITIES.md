# Skills And Capabilities Route

Choose the smallest capability set that covers the request.

1. Classify the task and risk.
2. Inspect the existing Capability Registry and project restrictions.
3. Select the active role.
4. Select only required skills/capabilities.
5. State the recommendation before substantive interactive work.

Capability selection is advisory and grants no authority. Project overlays may restrict or add links, but must not create a second independent registry. Missing or conflicting capability rules fail closed to the active role or owner.
